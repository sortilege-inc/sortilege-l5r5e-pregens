Build a samurai Open the Creator

Every character here exists to be picked up and played. Each is built to a real school, from the compendium's own rules text, and each carries a timeline: the same samurai at 0 XP, at 20, at 90, at 279 — so a table can start wherever it likes and a Game Master can see exactly what changed between one rank and the next.

The archive doubles as a coverage exercise. The aim is not only one character per school, but between them a working demonstration of as much of the game as possible — every technique, advantage, disadvantage, title, and piece of gear put in someone's hands at least once. The coverage ledger tracks how far along that is, honestly and in public.
